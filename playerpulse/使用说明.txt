PlayerPulse(律动播放器)5.2.0 —— 编译成 .deb 说明
================================================================

一、这是个什么东西
----------------------------------------------------------------
Theos 工程,iOS 越狱插件(tweak),包名 com.axs.playerpulse,注入 com.apple.springboard。
编译出来是一个 .deb,里面有两样:
  · AxsPlayerPulse.dylib      插件本体(带 PreferenceLoader 过滤器 plist)
  · AxsPlayerPulsePrefs.bundle 设置面板(设置 → 律动播放器)

必须是 Theos + iPhoneOS SDK 才能编,普通 Linux 上面直接 gcc 编不出来,iOS 的 Mach-O、
ldid 签名、deb 打包都是 Theos 那套工具在做。

本包已经把你需要的构建脚本备齐,源码一个字没动(保持你上传的原样)。


二、四条路,挑一条
----------------------------------------------------------------
【路 1·最省事】GitHub Actions(自带 workflow,不用本地环境)
  1) 把 playerpulse 整个目录推到 GitHub 仓库(默认分支 main)
  2) 仓库 Settings → Actions → General → Workflow permissions 选 "Read and write"
  3) Actions → "Build PlayerPulse" → Run workflow
  4) 跑完在 Releases / Artifacts 里下 .deb
  你自带的 .github/workflows/build.yml 用的就是 macOS 14 + Xcode 15.4 + iPhoneOS16.5 SDK,
  默认矩阵只打 rootless。要 rootful/roothide 就把矩阵里那两行注释打开。

【路 2·Linux 服务器 / 本机 Linux】
  cd playerpulse
  bash build-deb.sh rootless        # 或 rootful / roothide / all
  第一次会自动装依赖(apt)、拉 Theos、拉 iPhoneOS16.5 SDK,几百 MB,得等一会儿。
  之后每次编就很快。产物:packages/*.deb 和 dist/*.deb

【路 3·任意机器 + Docker(不污染本机环境)】
  cd playerpulse
  bash docker-build.sh rootless
  镜像里已经装好 Theos + SDK,产出一致。

【路 4·macOS】
  装 Xcode 命令行工具 + brew install ldid dpkg xz,然后同样 bash build-deb.sh rootless


三、打完自检(强烈建议)
----------------------------------------------------------------
  bash verify-deb.sh
会打印控制字段 + 包内完整文件清单,并逐项检查:
  · 架构字段是不是 iphoneos-arm64(rootless)
  · dylib / 过滤器 plist / PreferenceLoader plist / Preferences bundle 有没有缺
  · 路径前缀对不对(无根设备要 /var/jb/...,有根设备是 /Library/...)

装设备:
  · Dopamine / palera1n rootless → 装 rootless 包
  · 老 rootful 越狱(unc0ver 等) → 装 rootful 包
  · RootHide → 装 roothide 包
装错前缀的包装不上或者不生效,这是最常见的"编出来了但没效果"的原因。


四、源码里我看到的几个点(不影响能不能编出来,但建议改)
----------------------------------------------------------------
1) AxsPlayerPulseBuild.mk 里 ifneq 两个分支写的 TARGET 一模一样,等于没区分 rootful/rootless。
   无害,可以删掉 ifneq 只留一行。
2) control 里字段名写的是 "Sileodepiction",标准写法是 "SileoDepiction"(Sileo 2 起改推
   "Depiction")。不改也能装,只是详情页图标/截图可能不显示。
3) control 里 Architecture 写死 iphoneos-arm。打 rootless 时 Theos 会自动改成 iphoneos-arm64,
   但建议按 verify-deb.sh 的输出确认一次。
4) Depends 只有 mobilesubstrate, preferenceloader,没写系统下限。可以补 firmware (>= 16.0),
   免得老系统设备装了直接崩。
5) build.sh 不会自动 bump 版本号,连着打几次都是 5.2.0,Sileo 会认为"没有更新"而不提示升级。
   每次发版手动改 control 里的 Version(或加个 -N 后缀)。
6) README 里提到 scripts/doctor.py,但你上传的包里没有 scripts/ 目录 —— 不影响编译,只是
   那句"结构检查已通过"复现不了。
7) 设置面板图标只有 Resources/icon@2x.png,建议再补一张 icon.png(1x),老设备上不至于空白。


五、编不过的话,常见就这几条
----------------------------------------------------------------
· 报 "Set THEOS to a compatible Theos toolchain" → 没 export THEOS,用 build-deb.sh 跑它会自动处理。
· roothide 报错 → 上游 theos 不支持 roothide scheme,必须用 roothide/theos 这个 fork(脚本默认拉的就是它)。
· 报找不到 iPhoneOS16.5.sdk → 手动 git clone theos/sdks 做 sparse checkout 放到 $THEOS/sdks/。
· arm64e 链接报错(常见于非 Apple clang)→ 加 ARCHS_OVERRIDE=arm64 再跑:
      bash build-deb.sh rootless 前面加 ARCHS_OVERRIDE=arm64
  arm64 二进制在 arm64e 设备上照样能跑。
· 能编出来但装到设备上没反应 → 先确认包前缀和设备越狱类型对得上,再确认设置里
  「启用插件」打开了(它默认是关的),最后重放一首歌让 MediaRemote 推一次状态。
